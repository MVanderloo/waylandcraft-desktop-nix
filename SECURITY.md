# Security policy

## Supported versions

Security fixes are made on the `main` branch. This project has not published a
stable release series yet.

## Reporting a vulnerability

Please do not put vulnerability details in a public issue. If private
vulnerability reporting is enabled on the repository's **Security** tab, open
a draft security advisory with the affected revisions, reproduction steps,
impact, and any suggested mitigation. Otherwise, open a public issue that asks
only for a private contact channel.

Fix timing and disclosure depend on severity, exploitability, maintainer
availability, and whether an upstream dependency is involved.
