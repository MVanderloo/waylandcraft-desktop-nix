# Waylandcraft Desktop Policy

This client-side Fabric mod turns recoverable game states into desktop-session
policy. It targets only the versions in the repository's root flake and loads a
versioned manifest generated by the NixOS module.

- Named modifier chords remain global while a guest has hard keyboard capture.
  Each dispatches a tagged built-in action or an executable argument vector.
- Defaults and configuration are documented in
  [`docs/flake.md`](../docs/flake.md#policy-and-keybindings).
- Minecraft screens such as inventory, crafting, chat, and settings remain
  available.
- A configured keyboard-lock action replaces Waylandcraft's hard-coded Alt+Q
  toggle; without one, the upstream binding is left intact.

The Nix build compiles these sources directly against the fixed Minecraft and
Waylandcraft artifacts. The pinned Minecraft release is unobfuscated, so this
small mod does not need a remapping or Gradle dependency-resolution step.
